Como enviar ao PS4 (sem terminal)
  1. No PS4, abra o SSPI e mostre o QR code do Phone Companion; escaneie com o celular (mesma rede Wi-Fi).
  2. Aqui, toque em Copiar link no item desejado.
  3. Na página do SSPI no celular, aba Downloads → cole no campo Paste a download link → enviar.
  4. No PS4, o item aparece na fila do SSPI; acompanhe e instale por lá.

Validado automaticamente = o robô testou o link (responde, aceita Range) e leu a identidade do PKG. Não garante instalação. Instalação comprovada no PS4 = você relatou ter instalado e aberto aquele link exato.
